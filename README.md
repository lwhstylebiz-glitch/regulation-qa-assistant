# 📘 규정 Q&A 도우미 (로컬 / 완전 오프라인 RAG)

규정 PDF를 올리면, 직원이 자연어로 질문하고 **관련 조항을 근거(출처)와 함께** 답변받는 AI 도우미입니다.
LLM·임베딩을 모두 로컬 [Ollama](https://ollama.com)로 실행하므로 **데이터가 PC 밖으로 나가지 않습니다.**

> 해커톤 트랙 5(자유주제) 참가 작품

---

## ✨ 특징

- **조항 단위 청킹** — `제○조`·`제○조의○` 같은 규정 문서 구조를 인식해 조 단위로 잘라 검색 정확도를 높였습니다.
- **근거(출처) 표시** — 답변마다 참고한 조항·페이지·유사도를 함께 제시해 **환각 없이 규정 기반으로만** 답합니다.
- **완전 오프라인** — 외부 API·키 불필요. 어떤 규정 문서든 외부 전송 없이 안전하게 처리합니다.
- **DB 불필요** — 임베딩을 메모리(numpy)에 올려 코사인 유사도로 검색. 설치가 단순합니다.

## 🛠 기술 스택

| 구성 | 사용 기술 |
|------|-----------|
| UI | Streamlit |
| PDF 파싱 | pdfplumber |
| 임베딩 | Ollama · `bge-m3` (한국어 강함) |
| LLM | Ollama · `qwen2.5:7b` |
| 검색 | numpy 코사인 유사도 |

## 🚀 실행 방법

### 1. Ollama 설치 및 모델 다운로드

[ollama.com](https://ollama.com)에서 설치한 뒤:

```bash
ollama pull bge-m3
ollama pull qwen2.5:7b
```

### 2. 라이브러리 설치

```bash
pip install -r requirements_ollama.txt
```

### 3. 실행

```bash
streamlit run app_ollama.py
```

브라우저에 `localhost:8501`이 열립니다. 사이드바에서 규정 PDF를 업로드하고 질문하세요.

> 💡 첫 질문은 모델을 메모리에 올리느라 10~30초 걸립니다(정상). 두 번째부터 빨라집니다.
> 스캔(이미지) PDF는 텍스트 추출이 안 되니, 텍스트가 살아있는 PDF를 사용하세요.
