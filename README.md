# 📘 규정 도우미 (로컬 / 완전 오프라인 RAG)

규정 PDF를 올리면, 직원이 자연어로 질문하고 **관련 조항을 근거(출처)와 함께** 답변받는 AI 도우미입니다.
LLM·임베딩을 모두 로컬 [Ollama](https://ollama.com)로 실행하므로 **데이터가 PC 밖으로 나가지 않습니다.**

> 사내 AI 해커톤 트랙 5(자유주제) 참가 작품

---

## ✨ 주요 기능

**정확한 검색**
- **조항 단위 분할**: `제○조(제목)` 구조를 인식해 조항 단위로 자릅니다. 페이지를 넘어가는 조항도 온전히 유지하고, 본문 속 법령 인용("근로기준법 제60조에 따라")은 조항 시작으로 착각하지 않습니다.
- **의미 검색 + 단어 검색**: 임베딩(bge-m3) 의미 검색에 단어 일치 검색(BM25)을 섞어 규정 용어가 들어간 질문을 정확히 찾습니다.
- **표현 사전**: 직원이 쓰는 말을 규정 용어로 보강해 찾습니다. (월급날 → 임금 지급일, 여름휴가 → 하기휴가, 야근 → 연장근로 등)

**믿을 수 있는 답변**
- **근거 조항 표시**: 답변에 실제로 쓴 조항을 맨 위에 보여주고, 📚 전체 보기로 조항 원문 전체를 바로 열 수 있습니다.
- **근거 없으면 지어내지 않음**: 규정과 무관한 질문에는 "규정에서 확인할 수 없습니다"라고 답합니다. (근거 일치도 기준은 상단 ⚙️ 설정에서 조절)
- **숫자·조건은 원문 그대로**: 기간·금액·예외 조건을 바꾸지 않고 옮기도록 지시합니다.

**편의 기능**
- **이어서 질문하기**: "연차 며칠이에요?" 다음에 "그럼 3년 근무하면요?"처럼 앞 대화를 이어서 질문할 수 있습니다.
- **문서 맞춤 예시 질문**: 올린 문서의 조항 제목을 보고 예시 질문을 자동으로 만듭니다.
- **화면 구성**: 상단 한 줄에 답변 모델 선택 · 준비 상태 · 📝 내 질문 · ⚙️ 설정, 왼쪽 사이드바는 조항 보기 전용
- **📝 내 질문**: 지금까지 한 질문 목록(최근순, 근거 조항 표시). 누르면 그 답변 위치로 이동
- **조항 보기**: 답변 출처의 📚 전체 보기를 누르면 사이드바에 해당 조항 원문 전체가 열림
- **답변 스트리밍 + 응답 시간 표시**, 대화 내용 저장(⚙️ 설정)
- **자동 로드 + 예열**: 같은 폴더의 `취업규칙.pdf`를 켤 때 자동으로 불러오고, 분석 결과를 저장해 다음 실행부터 바로 뜹니다.

## 🛠 기술 스택

| 구성 | 사용 기술 |
|------|-----------|
| UI | Streamlit |
| PDF 파싱 | pdfplumber |
| 임베딩 (의미 검색) | Ollama · `bge-m3` |
| 답변 생성 (LLM) | Ollama · `qwen2.5:7b` (상단에서 변경 가능) |
| 검색 | numpy 코사인 유사도 + BM25 (한국어 2글자 단위) |

## 🤖 AI 적용 지점

1. **의미 임베딩**: 질문과 조항을 뜻으로 이해해 벡터로 변환 (`bge-m3`)
2. **의미 기반 검색**: 단어가 아닌 의미로 관련 조항 탐색
3. **답변 생성**: 찾은 조항을 근거로 답변 작성, 문서 맞춤 예시 질문 생성 (LLM)

## 🚀 실행 방법

### 1. Ollama 설치 및 모델 다운로드

[ollama.com](https://ollama.com)에서 설치한 뒤:

```bash
ollama pull bge-m3
ollama pull qwen2.5:7b
```

한국어 답변 품질을 비교해보고 싶다면 다른 모델도 받아서 상단의 모델 선택에서 고를 수 있습니다.

```bash
ollama pull exaone3.5:7.8b   # LG 한국어 특화 (비상업 라이선스)
ollama pull qwen3.5:4b       # 더 가볍고 빠름
```

### 2. 라이브러리 설치

```bash
python -m pip install -r requirements_ollama.txt
```

### 3. 실행

```bash
python -m streamlit run app_ollama.py
```

브라우저에 `localhost:8501`이 열립니다. 상단 바에 `✅ Ollama · ✅ bge-m3 · ✅ qwen2.5:7b · ✅ 예열`이 모두 뜨면 준비 완료입니다.

> 💡 처음 실행할 때는 모델 예열과 문서 분석 때문에 1~2분 걸립니다. 다음부터는 분석 결과를 저장해두어 바로 뜹니다.
> 스캔(이미지) PDF는 텍스트 추출이 안 되니, 텍스트가 살아있는 PDF를 사용하세요.

## 📄 시연용 문서

`취업규칙.pdf`는 고용노동부 **2026년 표준 취업규칙(일반 근로자용)**을 바탕으로 만든 **가상 회사(가나다주식회사) 규정**입니다.
양식의 빈칸(근무시간, 수습기간, 상여금 등)에는 예시값을 넣었고, 작성 요령(해설)은 제외했습니다.
실제 사내 규정은 대외비이므로 저장소에 올리지 않습니다. (`.gitignore`에서 PDF 제외)

## ⚙️ 조절할 수 있는 값 (`app_ollama.py` 상단)

| 설정 | 기본값 | 설명 |
|------|--------|------|
| `DEFAULT_GEN_MODEL` | `qwen2.5:7b` | 처음 선택되는 답변 모델 |
| `TOP_K` | 4 | 질문당 참고할 최대 조항 수 |
| `DEFAULT_MIN_SCORE` | 0.35 | 이보다 근거 일치도가 낮으면 "확인할 수 없음" 처리 |
| `KEYWORD_WEIGHT` | 0.3 | 검색 순위에서 단어 일치 점수 비중 |
| `SYNONYMS` | — | 직원 표현 → 규정 용어 사전 (줄 추가로 확장) |
